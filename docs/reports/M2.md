# M2 GUI 原生终端交互 报告

## 1. 完成情况

- 删除 GUI 的 composer 输入框、「发送」按钮与 `send_text` 命令（`index.html`、`main.ts`、
  `styles.css`、`commands.rs`、`ipc.ts`）。**已完成**。
- `terminal.ts`：`disableStdin: false`；接入 `@xterm/addon-fit`（ResizeObserver + 100 ms 防抖）
  与 `@xterm/addon-unicode11`（`term.unicode.activeVersion = "11"`）；`onData`/`onBinary`
  仅在控制者状态发送，非控制者在状态条提示「观察模式」。**已完成**。
- 新增 Tauri 命令 `send_input(session_id, data: Vec<u8>)`：**直接**经 `InputSender` 发送，
  不经过 pump 的请求队列，因此不会排在正在等待响应的请求后面；Rust 侧维护
  `stream_id`、输入偏移、已确认偏移与 256 KiB 未确认缓冲；>16 KiB 自动切块且偏移连续。**已完成**。
- 输出：pump → 独立 emitter 任务合并连续 Output（16 ms 空闲或累计 256 KiB 再 emit），
  前端 `term.write(Uint8Array)`；前端按偏移检查：重复跳过、缺口触发重新挂接
  （`applyOutput` 返回 false → `resyncSession`）。本地积压超 8 MiB 时丢弃并重新挂接。**已完成**。
- 快照事件：SnapshotBegin → `term.reset()` + `resize(cols, rows)`，分块写入，End 后恢复。**已完成**。
- 剪贴板与快捷键（`attachCustomKeyEventHandler`）：有选区 Ctrl+C 复制且不发送 `^C`，
  无选区发送 `^C`；Ctrl+Shift+C 复制；Ctrl+Shift+V / Ctrl+V 经 `term.paste()`（括号粘贴由 xterm
  按远端模式处理）；macOS 用 Cmd+C/Cmd+V 并设 `macOptionIsMeta: true`；剪贴板用
  `navigator.clipboard`，失败时提示而非静默。**已完成（Tauri 内可用性未实测）**。
- 屏蔽 WebView2 浏览器快捷键：Windows 通过 `with_webview` 取 `ICoreWebView2Settings3`
  `SetAreBrowserAcceleratorKeysEnabled(false)`；其他平台在终端容器上用捕获阶段
  `preventDefault` 拦 Ctrl+R / F5 / Ctrl+W / Ctrl+P / Ctrl+±/Ctrl+0。**已完成（未实测）**。
- 创建会话时用离屏测量终端（同字体、同容器）得到实际 fit 行列数传给 `Create`；
  获得控制权（挂接即控制或接管成功）后立即 `fit()` 并发送 `Resize`；观察者按会话尺寸显示
  （`Resized` → `view.resizeTo`）。**已完成**。
- 中文输入法（xterm.js 文本域默认行为）与 Unicode11 宽度。**已实现，未实测**。

## 3. 设计要点与偏离

1. **输入路径**：M1 的 `PumpCmd::Input` 已删除；`send_input` 命令直接调用
   `InputSender::send_input`，并用每会话 `input_gate`（tokio Mutex）串行化，保证偏移分配与
   帧发送同序。
2. **输出合并**：每个会话的 pump 把事件发给独立的 emitter 任务；emitter 用一个通道保证顺序，
   连续偏移合并到 16 ms/256 KiB 再 emit。合并需要原始字节，因此 Rust 侧新增直接依赖
   `base64`（把合并结果重新编码为既有事件契约）。
3. **剪贴板方案**：任务书允许 `tauri-plugin-clipboard-manager` 或 `navigator.clipboard` 二选一；
   本实现选 `navigator.clipboard`，避免新增插件与 capabilities 配置。**未在 Tauri 内实测**。
4. **`webview2-com` 的 cast**：为拿到 `ICoreWebView2Settings3` 需要 `windows-core::Interface`，
   因此 `src-tauri` 新增 `windows-core = "0.61"`（与 webview2-com 0.38.2 使用的
   windows 0.61 对齐）、`webview2-com = "0.38"`（仅 Windows）。
5. **创建尺寸**：在 `#terminal-panel` 里用同字体渲染一个隐藏的临时终端并 fit，取得行列数；
   不改变现有布局。
6. **未确认输入缓冲**：上限 256 KiB，超出丢弃最旧条目；M2 无重连，实际用于 M4 的重发。
7. **新增依赖**：前端 `@xterm/addon-fit`、`@xterm/addon-unicode11`（允许列表内）；
   Rust `webview2-com`、`windows-core`（允许列表内/为其所需）、`base64`（合并输出所需）。

## 6. 已知问题与风险

- 剪贴板读取失败时只有提示，没有回退通道（右键菜单属于 M8）。
- 若 `navigator.clipboard` 在 WebView2 不可用，Ctrl+C/V 会提示失败；可在复核后改用
  `tauri-plugin-clipboard-manager`。
- 未确认输入缓冲超限时静默丢弃最旧条目（偏移仍连续），M4 实现重连重发时要复核这一策略。
- 观察者收到 `Resized` 会 resize 本地视窗；控制者同时收到自己的尺寸变化，数值一致不会循环。
- `measureTerminalSize` 依赖面板在测量时已有布局；窗口极小时会退回最小 2 行列。
